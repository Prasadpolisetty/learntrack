# 21st.dev design references

LearnTrack's React dashboard layout takes design direction from the following public 21st.dev catalogue entries:

- React Dashboard Components collection: https://21st.dev/community/components/explore/react-js-dashboard
- Dashboard Sidebar by Arun Dass: https://dev.21st.dev/@arunjdass/components/dashboard-sidebar
- Progress Metric Card by Mak VieSAinte: https://dev.21st.dev/@makviesainte/components/progress-metric-card

The implementation in `src/App.jsx` is project-authored React. The visual references informed the dashboard shell, navigation hierarchy, metric cards, progress display and responsive layout. The 21st.dev component source itself has not been copied into this repository.
